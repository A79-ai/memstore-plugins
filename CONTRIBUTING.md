# Contributing

Thanks for helping. This repository is published from memstore's private source repository on every release, so:

- **Issues are the best way in.** Bugs, rough edges, feature requests and docs gaps are all welcome. Use the issue
  templates; for a bug, `/memstore:status` output (with anything private removed) helps most.
- **Pull requests** to the plugin files can't be merged here directly, because the next release overwrites them.
  Open one anyway if a diff says it best, and we'll carry it upstream with credit.
- **Security issues** go through [SECURITY.md](SECURITY.md), never a public issue.
